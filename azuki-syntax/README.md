# Azuki Syntax Highlighting

This VS Code extension adds syntax highlighting for [Azuki](https://github.com/kylejlin/azuki) grammars (`.azuki` files).

Code injection strings use plain string coloring. Both `rust"..."` and `rust#"..."#` are supported, including multiline strings and additional hashes.

For a local preview, open this directory in VS Code and press F5. Open an `.azuki` file in the Extension Development Host window.

To install a packaged extension, run **Extensions: Install from VSIX...** in VS Code and select the `.vsix` file.
